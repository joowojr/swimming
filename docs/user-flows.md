# User Flows

## 1. 개인 집중 세션

```mermaid
flowchart TD
    A[폴더 대시보드] --> B[폴더 선택]
    B --> C[폴더 상세]
    C --> D[Task 선택]
    D --> E[집중 시작]

    E --> F[세션 설정]
    F --> F1[공간 선택]
    F --> F2[집중 시간 선택]

    F1 --> G{필수 설정 완료?}
    F2 --> G

    G -- 아니오 --> F
    G -- 예 --> H[개인 세션 생성]

    H --> I[개인 세션 화면]

    I --> I1[현재 Task 확인]
    I --> I2[Timer 진행]
    I --> I3[Music 설정]
    I --> I4[Note 작성]
    I --> I5[집중 모드]

    I --> J{세션 종료}

    J --> K[세션 기록]
    K --> K1[Task 완료 여부]
    K --> K2[한 줄 메모]

    K --> L[세션 기록 저장]
    L --> M[폴더 진행 상태 반영]
    M --> C
```

### 핵심 규칙

* 개인 세션은 `Project → Task`에서 시작한다.
* 세션 시작 전 필수 설정은 `공간`, `집중 시간`으로 제한한다.
* 음악과 노트는 세션 진행 중 변경할 수 있다.
* 세션 종료 시 함께 남기는 세션 기록으로 Task 진행 상태를 갱신한다.
* 세션 이력은 기록 작성 여부와 관계없이 보존한다.

## 2. 빠른 재진입

```mermaid
flowchart TD
    A[폴더 대시보드] --> B[이어서 하기]

    B --> C[최근 작업 정보 조회]
    C --> C1[최근 Task]
    C --> C2[최근 공간]
    C --> C3[최근 세션 시간]

    C1 --> D[세션 설정]
    C2 --> D
    C3 --> D

    D --> E[이전 설정 기본값 제공]

    E --> F{수정할 설정이 있는가?}

    F -- 예 --> G[공간 또는 시간 수정]
    G --> H[개인 세션 생성]

    F -- 아니오 --> H

    H --> I[개인 세션 화면]
```

### 핵심 규칙

* 재방문 사용자의 반복 진입 단계를 최소화한다.
* 최근 Task, 공간, 세션 시간을 기본값으로 제안한다.
* 사용자는 필요한 값만 수정하고 바로 세션을 시작할 수 있다.

## 3. 그룹 세션 참여

```mermaid
flowchart TD
    A[그룹 세션 목록] --> B[그룹 Room 선택]

    B --> C[Room 상세]
    C --> C1[공간 확인]
    C --> C2[시작 시간 확인]
    C --> C3[진행 시간 확인]
    C --> C4[현재 참여 인원 확인]

    C --> D[참여하기]

    D --> E[내 목표 설정]

    E --> F{목표 유형}
    F -- 기존 Task --> G[Project Task 선택]
    F -- 임시 목표 --> H[Ad-hoc Goal 작성]

    G --> I[그룹 세션 입장]
    H --> I

    I --> J[그룹 세션 화면]

    J --> J1[내 목표 표시]
    J --> J2[공용 Timer]
    J --> J3[참가자 Presence]
    J --> J4[개인 Music]

    J --> K{세션 종료 또는 나가기}

    K --> L[세션 기록]
    L --> L1[Task 진행 상태 반영]
    L --> L2[세션 기록 저장]

    L --> M[그룹 세션 목록]
```

### 핵심 규칙

* 그룹 세션에서는 공간과 시간은 Room이 결정한다.
* 사용자는 입장 전에 자신의 목표만 설정한다.
* 목표는 기존 Task 또는 임시 목표 중 하나를 선택할 수 있다.
* 공용 Timer는 사용자 개인이 변경할 수 없다.
* Music은 개인 설정으로 유지한다.
* 참가자는 채팅보다 Presence 중심으로 표현한다.

## 4. 개인 세션 종료 및 기록

```mermaid
flowchart TD
    A[개인 세션 진행] --> B[종료 선택]

    B --> C[실제 집중 시간 확정]
    C --> D[세션 기록 화면]

    D --> E{Task가 연결되어 있는가?}

    E -- 예 --> F[Task 상태 입력]
    F --> F1[완료]
    F --> F2[진행 중]

    E -- 아니오 --> G[세션 메모만 작성]

    F1 --> H[선택적 한 줄 메모]
    F2 --> H
    G --> H

    H --> I{기록을 남기는가?}

    I -- 예 --> J[기록과 함께 종료]
    I -- 건너뛰기 --> K[기록 없이 종료]

    J --> L[Session 완료 처리]
    K --> L

    L --> M[폴더 또는 이전 화면으로 복귀]
```

### 핵심 규칙

* 세션 기록은 종료와 한 번에 저장한다. 기록 유무가 세션의 종료 여부나 실제 집중 시간을 바꾸지 않는다.
* 사용자가 기록을 건너뛰어도 세션은 정상 종료된다.
* Task가 연결된 경우에만 Task 진행 상태를 갱신한다.

## 5. 폴더 및 Task 관리

```mermaid
flowchart TD
    A[폴더 대시보드] --> B{사용자 행동}

    B -- 폴더 생성 --> C[새 폴더]
    C --> C1[이름]
    C --> C2[설명]
    C --> C3[목표 날짜]
    C1 --> D[폴더 저장]
    C2 --> D
    C3 --> D

    B -- 폴더 선택 --> E[폴더 상세]

    E --> F{Task 관리}

    F -- 생성 --> G[Task 작성]
    G --> H[Task 저장]

    F -- 수정 --> I[Task 수정]
    I --> H

    F -- 완료 --> J[Task 완료 처리]

    H --> E
    J --> E

    E --> K[Task에서 집중 시작]
    K --> L[개인 집중 세션 Flow]
```

### 핵심 규칙

* Project는 장기 목표 단위다.
* Task는 실제 집중 세션과 연결되는 실행 단위다.
* 폴더 진행률은 Task 상태를 기반으로 보여준다.
* Task에서 바로 개인 집중 세션으로 진입할 수 있어야 한다.

## 8. Google 로그인

```mermaid
flowchart TD
    A[Google 로그인 선택] --> B[Google 인증]
    B --> C{Google subject로 가입된 사용자인가?}

    C -- 예 --> D[앱 JWT 발급]
    C -- 아니오 --> E[새 사용자 생성]
    E --> D

    D --> F[로그인 완료]
```

### 핵심 규칙

* Google ID 토큰의 서명, issuer, audience, 만료와 이메일 검증 여부를 백엔드에서 확인한다.
* 사용자 식별에는 변경될 수 있는 이메일이 아니라 Google `sub`를 사용한다.
* Google `sub`가 처음 확인되면 새 사용자를 생성한다.
* 앱은 Google 토큰을 세션으로 사용하지 않고 자체 access token과 refresh cookie를 발급한다.

# Core Flow Summary

```mermaid
flowchart LR
    A[Project] --> B[Task]
    B --> C[Session Setup]
    C --> D[Personal Focus]
    D --> E[세션 기록]
    E --> A

    F[Group Room] --> G[Goal]
    G --> H[Group Focus]
    H --> I[세션 기록]

    J[Home] --> K[Continue]
    K --> D
```

## 제품 흐름 원칙

1. **Project와 Focus는 직접 연결한다.**

    * Task를 관리하는 것에서 끝나지 않고 실제 집중 행동으로 이어져야 한다.

2. **개인 세션 시작 전 설정은 최소화한다.**

    * 공간
    * 집중 시간

3. **세션 진행 중의 조작은 My Desk 안에서 처리한다.**

    * Task
    * Timer
    * Music
    * Note
    * Focus Mode

4. **그룹 세션은 개인 세션과 다른 진입 흐름을 가진다.**

    * 개인: `Task → Space → Focus`
    * 그룹: `Room → Goal → Focus`

5. **모든 Focus 경험은 기록으로 돌아온다.**

    * Focus → 세션 기록 → Task / Project Progress

6. **재방문 사용자는 가능한 한 빠르게 Focus로 복귀할 수 있어야 한다.**

    * `Home → 이어서 하기 → Focus`

7. **Social 기능보다 Presence를 중요한다.**

    * 그룹 세션의 핵심은 대화가 아니라 함께 집중하고 있다는 감각이다.
