# F07. 몰입 환경에서 개인 세션을 진행한다

- PRD: PS-3, PS-5, CITY-1, MUSIC-1, MUSIC-2
- Depends on: F06

## Goal

사용자가 원하는 공간과 음악을 선택하고, 방해 요소를 줄인 몰입형 화면에서 개인 세션을 진행한다.

## User Flow

개인 세션 설정 → 공간·집중 시간 선택 → 세션 시작 → 풀블리드 공간 진입 → 음악·위젯·집중 모드 조작 → 세션 종료

## Acceptance Criteria

- 사용자는 개인 세션을 시작하기 전에 현재 제공되는 공간 중 하나를 선택한다.
- 선택한 공간은 세션 기록에 저장되고 세션을 다시 조회해도 유지된다.
- 개인 세션 진행 화면은 선택한 공간의 배경을 화면 전체에 표시한다.
- 진행 화면에는 현재 Task, 타이머와 음악 제어를 코너의 반투명 위젯으로 표시한다.
- 사용자는 세션 진행 중 음악을 재생·정지하고 제공되는 음악 선택지를 변경할 수 있다.
- 사용자는 개인 세션의 음악 위젯에 YouTube 영상 또는 재생목록 주소를 입력해 플레이어를 불러올 수 있다.
- 세션에는 사용자가 가장 최근에 입력한 YouTube 주소 하나만 저장하며 새 주소를 입력하면 기존 주소를 대체한다.
- 사용자가 같은 세션에 다시 진입하면 저장된 주소를 불러오되 자동으로 재생하지 않는다.
- YouTube 플레이어는 브라우저 자동재생 정책에 따라 사용자의 재생 조작 이후 시작하며, 재생 컨트롤이 보이는 상태로 제공한다.
- 음악 설정은 개인에게만 적용되며 세션 타이머 계산이나 기록에 영향을 주지 않는다.
- 사용자는 개별 위젯을 접거나 펼칠 수 있고, 모든 위젯을 접으면 배경만 남는다.
- 위젯 위치는 F06에서 정한 고정 배치를 사용하며 위치 좌표나 사용자 드래그 결과는 저장하지 않는다.
- 집중 모드를 켜면 앱 내부 내비게이션과 비필수 안내를 숨기고 세션에 필요한 조작만 유지한다.
- 웹 애플리케이션이 제어할 수 없는 운영체제·브라우저 알림을 차단했다고 표현하지 않는다.
- 집중 모드를 해제하거나 세션을 종료하면 숨겼던 앱 내 조작 요소를 다시 사용할 수 있다.
- 키보드만으로 위젯과 주요 세션 조작에 접근할 수 있으며, 배경 위의 텍스트와 조작 요소는 읽을 수 있는 대비를 유지한다.
- 화면 크기가 달라져도 타이머와 종료 조작이 배경이나 다른 위젯에 가려지지 않는다.

## Out of Scope

- 3~5개 도시 콘텐츠 확충과 도시별 큐레이션
- 실시간 날씨·현지 시간 동기화
- YouTube 외 외부 음원 서비스 연동
- 사용자별 위젯 설정과 음악 상태의 서버 저장·재진입 복원
- 운영체제와 브라우저 알림의 강제 차단
- 위젯 위치 사용자 저장과 자유 배치
- 그룹 참가자·목표 위젯

## API Contract

### 도시·공간 목록 조회

```http
GET /api/cities
```

- `200 OK`와 도시별 공간 목록을 반환한다.
- 공간은 배경 에셋 타입(`IMAGE` 또는 `VIDEO`), 배경 URL과 nullable 기본 음악 URL을 포함한다.

### 개인 세션 시작

```http
POST /api/sessions
```

```json
{
  "taskIds": [10, 11],
  "placeId": 1,
  "plannedDurationSec": 2700
}
```

- `placeId`는 필수이며 존재하지 않으면 `PLACE_NOT_FOUND` ProblemDetail을 반환한다.
- `201 Created`와 생성된 세션을 반환하며 응답에는 선택한 공간과 nullable `musicUrl`이 포함된다.

### 세션 조회

```http
GET /api/sessions/{sessionId}
GET /api/sessions/active
```

- 단건 조회는 진행·종료 상태와 관계없이 본인의 세션을 조회한다.
- 활성 세션 조회는 진행 중인 세션이 없으면 `204 No Content`를 반환한다.
- 응답에는 선택한 공간과 해당 세션의 마지막 `musicUrl`이 포함된다.

### 세션 음악 URL 저장

```http
PUT /api/sessions/{sessionId}/music-url
```

```json
{
  "musicUrl": "https://www.youtube.com/watch?v=example"
}
```

- 진행 중인 본인의 세션만 변경할 수 있다.
- 새 URL은 기존 URL을 대체하며 null은 저장된 URL을 제거한다.
- YouTube 영상 또는 재생목록의 HTTP(S) 주소만 허용하며 최대 길이는 2,048자다.
- 성공 시 `204 No Content`를 반환한다.
